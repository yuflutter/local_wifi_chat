
# Local WiFi Chat - Backend

HTTP/WS сервер для текстового чата и голосовой комнаты. Написан на Golang.

Все файлы фронтенда должны быть встроены в бинарник бекенда.
После сборки фронтенда скопируйте web-бандл в папку "./frontend_bundle", после чего соберите или запустите бекенд. Если такой папки нет - создайте её. См. файл ../build.sh
